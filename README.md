# 🎤 Argue With Me

**An AI sparring partner that argues back.**

Argue With Me is a mobile-friendly web app that trains students in debating, public speaking, and oral exams (viva). Pick a topic, and the AI takes the opposite side and challenges you by voice, attacking your weakest points in real time. When the debate ends, it gives you a detailed scorecard showing exactly how to improve.

## ✨ Features

- **Three modes:** Debate (AI takes the opposing side), Viva (AI acts as a strict examiner), and Devil's Advocate (AI challenges whatever you say)
- **Voice conversations:** speak your answers and hear the AI respond, using the Web Speech API
- **Level selection:** Class 6-8, Class 9-10, Class 11-12, or College, which adjusts vocabulary and difficulty
- **Pressure timer:** 60 seconds per answer to simulate real exam and debate conditions
- **Expressive AI avatar:** shows thinking, impressed, and skeptical reactions
- **Detailed scorecard:** scores for logic, evidence, clarity, confidence, and rebuttal strength, plus your best argument, weakest moment, factual corrections, logical fallacies spotted, and three tips to improve
- **Progress tracking:** past sessions and scores are saved locally, with a graph showing improvement over time
- **Typing fallback:** works without a microphone

## 🛠️ Built With

- Gemini API (reasoning, argument generation, and scoring)
- Web Speech API (SpeechRecognition and SpeechSynthesis)
- HTML, CSS, and JavaScript
- localStorage for saving history
- Created using Google AI Studio

## 🚀 Getting Started

1. Clone the repository:
   `git clone https://github.com/your-username/argue-with-me.git`
2. Add your Gemini API key (see the configuration notes in the code). Never commit your key to GitHub.
3. Open the app in **Google Chrome** for the best voice support.
4. Choose a topic, pick a mode, and start arguing!

## 🎯 Use Cases

- Preparing for school debates and elocution competitions
- Practicing for viva and oral exams
- Improving critical thinking and public speaking
- Getting comfortable defending your opinions under pressure

## 🔒 Notes

- The AI is designed to be tough but respectful, and all content is age-appropriate for students.
- The AI is instructed not to invent statistics or sources, but always verify important facts yourself.
- Your session history is stored only in your own browser.
